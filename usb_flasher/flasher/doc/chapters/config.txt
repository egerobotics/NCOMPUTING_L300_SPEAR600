== Configuration ==

Configuration file of the device contains the information regarding the
partition details on the NAND and NOR flashes. Configuration files
(setupXXX.ini) is stored in the configuration folder of the package.

These configuration details is used by the flashing utility to program
different modules (xloader, u-boot, Linux and rootfs) at their right
partition or offset. This configuration or partition layout may vary
from board to board.

Setup Partition Menu of the GUI utility retrieves the information
regarding the partition of the device from such configuration files.
Each device has separate configuration file. Depending on the device
selected from the combo box, configuration file is loaded in the
utility. 

Configuration file of the device can be changed either directly editing
the configuration file or with the help of setup partition menu
(GUI). Configuration file can be print on command terminal in the command
interface (refer config command)

The Configuration file for the SPEAr900 device is as following which can
even be edited manually.

    Nor@0x10000
    Xloader@0@1
    UBoot@1@3
    Linux Image@5@44
    File System@49@79
    Nand@0x20000
    Xloader@0@1
    Xloader@1@1
    Xloader@2@1
    Xloader@3@1
    Uboot@4@12
    Linux Image@16@48
    File System@64@8128

NOTE: Xloader in nand is replicated 4 times in order to create
redundancy against NAND block failures
